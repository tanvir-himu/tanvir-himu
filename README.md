## About me

I am a computer science student who builds web projects and studies security alongside them. Most of my work is full-stack: a React front end, a Node or PHP back end, and a database that is set up with safe defaults from the start. I care about code that is easy to read and hard to break, because the people using it should not have to think about either.

My security side shows up in my repositories too. I have written projects on cryptography, hashing, steganography and phishing detection, so I know how things get attacked and I build with that in mind.
